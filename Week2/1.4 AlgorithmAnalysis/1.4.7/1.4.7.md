Brute-force

int count = 0;
int n = a.length;
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        for (int k = j + 1; k < n; k++) {
            if (a[i] + a[j] + a[k] == 0) {
                count++;
            }
        }
    }
}

Số lần lặp của vòng k (vòng trong cùng):
    Ứng với mỗi cặp $(i, j)$ cố định, $k$ chạy từ $j + 1$ đến $n - 1$.
    Tổng số bộ ba $(i, j, k)$ với $0 \le i < j < k < n$ chính là tổ hợp chập 3 của $n$ phần tử:
        $$C_n^3 = \frac{n(n-1)(n-2)}{6} \sim \frac{n^3}{6}$$
Các phép toán bên trong vòng lặp:
    Phép cộng số học: a[i] + a[j] + a[k] thực hiện $2$ phép cộng.Phép so sánh: == 0 thực hiện $1$ phép so sánh.
    Phép tăng biến đếm / điều kiện vòng lặp (i++, j++, k++, check i < n, v.v.): tốn thêm các phép so sánh/tăng chỉ số.
Tổng chi phí xấp xỉ:   
    Số lần thực hiện phép kiểm tra điều kiện a[i] + a[j] + a[k] == 0 là $\frac{n(n-1)(n-2)}{6} \approx \frac{1}{6}n^3$.
    Do đó, chi phí thời gian chạy theo mô hình tiệm cận là $O(N^3)$ (bậc 3), với hằng số xấp xỉ $\frac{1}{6}$ (tức $\frac{N^3}{6}$ phép toán cộng/so sánh)."""
