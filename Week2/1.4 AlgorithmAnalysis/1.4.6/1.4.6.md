a.  int sum = 0; 
    for (int n = N; n > 0; n /= 2) 
        for(int i = 0; i < n; i++) sum++; 

Phân tích:
    Vòng ngoài biến n giảm một nửa sau mỗi bước: $N, N/2, N/4, \dots, 1$ (có khoảng $\log_2 N$ bước).
    Vòng trong chạy từ $0$ đến $n-1$ (tốn $n$ phép tính).
    Tổng số phép tính là: $N + \frac{N}{2} + \frac{N}{4} + \dots + 1 = N \left(1 + \frac{1}{2} + \frac{1}{4} + \dots\right) = N \times 2 = 2N$.
Bậc tăng: $O(N)$ (tuyến tính).

b.  int sum = 0;
    for (int i = 1; i < N; i *= 2)
        for (int j = 0; j < i; j++) sum++;

Phân tích:
    Vòng ngoài i tăng gấp đôi: $1, 2, 4, 8, \dots, 2^{\lfloor \log_2 N \rfloor}$.
    Vòng trong chạy tương ứng với giá trị hiện tại của i là $i$ lần.
    Tổng số lần lặp: $1 + 2 + 4 + \dots + N/2 = N - 1$.
Bậc tăng: $O(N)$ (tuyến tính).

c.  int sum = 0;
    for (int i = 1; i < N; i *= 2)
        for (int j = 0; j < N; j++) sum++;

Phân tích:
    Vòng ngoài i tăng gấp đôi: chạy khoảng $\log_2 N$ lần.
    Vòng trong j chạy từ $0$ đến $N-1$ (chạy đúng $N$ lần cho mỗi bước của i).
    Tổng số lần lặp: $\log_2 N \times N$.
Bậc tăng: $O(N \log N)$ (tuyến tính - loga).
